## Example

```text
a = 2
b = 3
```

> Returns **`5`**

---

## Function Description

Complete the `solveMeFirst` function.

| Parameter | Type  | Description     |
| :-------: | :---: | :-------------- |
|  `a`      | `int` | the first value |
|  `b`      | `int` | the second value |

### Returns

| Type  | Description          |
| :---: | :------------------- |
| `int` | the sum of `a` and `b` |

---

## Constraints

```text
1 <= a, b <= 1000
```
